# 🚀 Ecom-Agent-Router (윈들리 AI 상품 가공 조수)

> **"엑셀만 넣으면 월 1억 셀러 MD가 상품명, 태그, 상세설명을 알아서 뚝딱 고쳐주는 셀러 전용 AI 자동화 도구"**

[**English Guide**](./README.md) | [**쉽게 배우는 한국어 가이드**](./README_KR.md)

---

## 💡 이 도구는 무엇인가요?

윈들리(Windly)나 도매 사이트에서 가져온 해외 상품 데이터는 **상품명이 어색하고, 상표권 위험 단어가 섞여 있으며, 그대로 올리면 안 팔립니다.**

이 도구를 사용하면 AI가 **인기 카테고리별 1등 전문 MD(상품기획자)**로 변신하여, 네이버 쇼핑과 쿠팡에서 검색이 잘 되고 잘 팔리는 프로셀러 수준의 상품으로 **3초 만에 자동으로 재작성**해 줍니다!

---

## 🔥 3가지 핵심 자랑거리

### 1. 🎭 상품 종류에 따라 AI가 알아서 '전문 MD'로 변신합니다
- **미니 밥솥/에어프라이어 올릴 때** ➔ `7년차 자취생 전문 MD`로 변신! ("원룸 설거지 귀찮음 200% 해결" 강조)
- **옷/잡화 올릴 때** ➔ `성수동 스타일 패션 MD`로 변신! ("체형 보정 핏, 찰랑거리는 원단" 강조)
- **전자기기 올릴 때** ➔ `테크 덕후 IT MD`로 변신! ("고속 충전, C타입 완벽 호환" 강조)

### 2. 🕵️‍♂️ 잘 파는 경쟁사 상품의 '불만/약점'을 알아서 공격합니다
- 네이버/쿠팡에서 제일 잘 파는 상위 경쟁 상품들을 분석하여, **"경쟁사 제품의 불편한 점(소음, 세척 어려움 등)"**을 당사 상품의 **강점(USP)**으로 바꿔서 상세페이지에 적어줍니다.

### 3. 🛡️ 샤오미, 애플 등 '상표권 위험 단어'를 알아서 걸러줍니다
- 무심코 올렸다가 마켓 정지당할 수 있는 타사 브랜드명이나 과장 표현("세계 1위", "절대 고장 안 남")을 **100% 안전한 표현으로 자동 교정**합니다.

## 🚀 딱 3단계! 초간단 사용법

### 1단계: 엑셀 파일 넣기
- 윈들리에서 다운로드한 엑셀(CSV) 파일을 `input/` 폴더에 넣습니다.

### 2단계: AI에게 명령하기
- 채팅창에 한 줄만 치세요:
  ```text
  @product-customizer input 폴더 엑셀 가공해줘.
  ```

### 3단계: 결과 파일 가져오기
- `output/` 폴더에 완성된 엑셀(CSV)과 예쁜 마크다운 결과가 만들어집니다.
- 이 엑셀을 네이버 스마트스토어나 쿠팡에 그대로 등록하면 끝!

## 📂 폴더 구조 한눈에 보기

```text
Windly-Product-Custom/
├── input/       # 👈 원본 엑셀 파일 넣는 곳
├── output/      # 👈 AI가 다 고친 엑셀/마크다운 나오는 곳
└── GUIDE.md     # 👈 초보 셀러 가이드북
```
